# نظام أرشفة ذكي حسب المحتوى
**Smart Content-Based Archiving System** · التصنيف: منصة تجارية

> وثيقة تعريفية بالمشروع (المواصفات والتقنيات) — لا تتضمن الكود المصدري.
> Project overview document — source code is not included.

## نبذة عن المشروع
نظام أرشفة يبحث داخل النصوص والحقول والمرفقات وليس مجرد مجلدات، ما يختصر وقتاً كبيراً في المكاتب.

## أبرز النقاط
- بحث نصي كامل داخل المستندات والمرفقات
- فهرسة الملفات الممسوحة عبر OCR
- وسوم وإصدارات وتحكم بالوصول

## الدور
مطوّر منصات أعمال: تحليل المتطلبات وبناء النظام ولوحة الإدارة وقاعدة البيانات والتقارير.

## التقنيات المستخدمة
Python, FastAPI, Elasticsearch, Tesseract OCR, MinIO, React, Docker
