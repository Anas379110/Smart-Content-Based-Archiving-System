# Smart Content-Based Archiving System
**Smart Content-Based Archiving System** · Category: Commercial platform

> Project overview document (specifications and technologies) — source code is not included.

## Project summary
An archiving system that searches inside texts, fields, and attachments rather than just folders, which saves significant time in offices.

## Highlights
- Full-text search within documents and attachments
- Indexing of scanned files via OCR
- Tags, versioning, and access control

## Role
Business Platforms Developer: requirements analysis and building the system, admin panel, database, and reports.

## Technologies used
Python, FastAPI, Elasticsearch, Tesseract OCR, MinIO, React, Docker
